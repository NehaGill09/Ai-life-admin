LOCAL-FIRST BY DESIGN

Your documents stay on this device.

Files, extracted text, and metadata are stored in your configured data directory. LifeAdmin does not require an account or automatically upload documents to a cloud service.

Network AIOptional · disabled by default
⌕

Local extraction

Text extraction, keyword retrieval, date/amount heuristics, and PII pattern checks run locally. OCR requires the optional Python packages and Tesseract system binary.

✦

Optional AI provider

If you configure an OpenAI-compatible endpoint, API key, and model in environment variables, retrieved excerpts may be sent to that provider to answer questions. Review its privacy terms first.

⚑

Handle sensitive files carefully

This initial release stores uploaded originals without application-level encryption. Use full-disk encryption, a private user account, and trusted backups. Do not upload files to shared or public machines.

↻

Backups & deletion

Keep your own protected backups of the data directory. Deleting a document removes its stored file and record, but cannot erase copies in backups or your operating system's history.
